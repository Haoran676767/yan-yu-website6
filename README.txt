打开 index.html 即可在浏览器查看，无需安装依赖，也无需联网。
用编辑器打开整个文件夹即可修改。

首页：index.html
样式：style.css
交互：script.js
碰撞推移：collision.js
素材及本地思源宋体：assets/

建筑图标支持鼠标或触屏拖动，碰撞时直接推移，松开即停。键盘 Tab 选择图标，方向键可移动；按住 Shift 加大移动距离。点击建筑可打开介绍页；拖动后不会误跳转。介绍页左上角的小亭子返回首页。
所有原始 PNG 保持不变，通过页面裁切透明边距。

顶部 EN / 中文按钮切换建筑名称、城市、构造提示和建筑介绍。
介绍页：pages/；介绍页样式与交互：detail.css、detail.js。
介绍文字参考来源：SOURCES.md。

添加建筑：列表末尾点击圆圈加号，上传PNG/JPEG/WebP图片并填写名称和介绍。新增内容保存在当前浏览器的本地存储中，不会写入ZIP，也不会自动同步给其他设备或访客；清除浏览器数据会删除新增内容。自填文字按原文显示，不自动翻译。建议使用编辑器的本地预览服务打开网站，以保证各页面共享浏览器存储。
语言通过页面链接传递，介绍页和返回首页均保留选择。
